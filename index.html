📰 AI 新聞結構化分析工具

1. 做了什麼 (Overview)

本專案使用 Python 與 OpenAI LLM 打造自動化結構化分析工具，能將新聞自動濃縮為 JSON 格式的標題、三重點與情緒評估。

2. 怎麼執行 (How to Run)

git clone 你的專案網址
cd my-ai-project
cp .env.example .env  # 填入金鑰
uv run main.py

3. 執行結果 (Result)

{
  "title": "臺灣開放銀行導入 AI 審查",
  "summary_points": ["合規時間縮短至數小時", "降低新創合作門檻", "提升金融體驗"],
  "sentiment": "正向"
}

4. AI 使用說明 (AI Usage & Reflection)

  • 使用的 AI 工具： 本專案開發過程使用 ChatGPT 與 Gemini 協助撰寫 main.py 的 JSON 結構語法與 index.html 排版。
  • 應用位置： 程式碼架構設計與 Prompt 調整。
  • 自我修改與驗證： 嚴格檢查並將 .env 加入 .gitignore，確保機敏金鑰不會外洩。
